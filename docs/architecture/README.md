# Architecture Specification

Formal specifications for the air-engine verification infrastructure.

## Planned Documents

- **AIR Schema** — Analysis Intermediate Representation metamodel (structural, semantic, and derived layers).
- **Contract Model** — Property and invariant definitions, versioning, and evaluation semantics.
- **Verification Pipeline** — End-to-end flow from capture to diagnostic artifacts.

Specifications will be added incrementally as the MVP is implemented.
